# Roadmap

## v0.1 — Foundation and block editor

Implement the scope and acceptance criteria in [SPEC-0001](specs/SPEC-0001-foundation-and-block-editor.md): portable block model and Markdown codec, safe block commands, and a native macOS Markdown document editor. No workspaces, search, sync, rich text, embedded media, math, diagrams, or charts are included.

Future releases require separate numbered specifications before implementation.
